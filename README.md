# Heal Care • Contemporary Apothecary & Modern Medicine

An elevated digital dispensary balancing clinical pharmaceutical rigor with timeless apothecary care. Features authentic prescription medicines, hospital-grade surgical equipment, and advanced derma cosmetics.

## ✨ Features

- **Interactive Hero Experience:** 300-frame scroll-synchronized product formulation visual scrub.
- **Glassmorphic Transparent Navbar:** Modern frosted glass design with dynamic scroll states.
- **Continuous Reviews Carousel:** Infinite smooth left-to-right verified patient & doctor testimonials ticker.
- **Digital Dispensary Workflows:**
  - Prescription upload with instant pharmacist verification.
  - Interactive Drug-Herb Interaction Checker.
  - Live order tracking and express 2-hour doorstep delivery.
  - Instant WhatsApp direct consultation & ordering.
  - Curated categories with instant search & quick view modals.
- **Luxury Editorial Typography:** Playfair Display, Plus Jakarta Sans, Outfit, and Cormorant Garamond.

## 🚀 Tech Stack

- **Framework:** React 19 + TypeScript
- **Styling:** Tailwind CSS v4 + Custom Glassmorphism
- **Icons:** Lucide React
- **Animations:** Motion + GPU-accelerated CSS Keyframes
- **Bundler:** Vite

## 🛠️ Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/isthatnkhl-byte/heal-care-pharmacy.git
cd heal-care-pharmacy

# Install dependencies
npm install

# Run the development server
npm run dev
```

## 🌐 Deploying to Vercel

1. Import the repository on [Vercel](https://vercel.com/new).
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**!
